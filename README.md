# 一卦 Minecraft

用錢幣與籌策起卦，在 Minecraft 裡閱讀《易經》、收集六十四卦，讓卦象為探索與生存帶來變化。聊天會告訴你本卦、動爻、變卦與遊戲效果；想讀經文時，再打開書本。

**0.2.1 公開測試版。** 新增完整進度網格、兩分鐘稀有狀態、生物時間虛影、九格寬累積分海、永久生態障路、鳳翼飛行與更多回溯互動。完整建置與遊戲內 12 案例已通過，實際載入 13 個外部模組；鳳翼第一人稱畫面與 FUTURE／PAST 分離虛影也已確認。這是本機 IntegratedServer 測試，最新真正 TCP、獨立伺服器及任意整合包仍待驗收；先前 0.2.0 真正 TCP 基線與完整範圍見 [驗收紀錄](docs/VALIDATION.md)。下載與各平台上架／審核以官方頁面為準。效果是遊戲改編，並非經文的唯一解釋或現實行動建議。

## 安裝環境

| 項目 | 版本 |
| --- | --- |
| Minecraft | Java 版 26.3 |
| Java | 25 |
| 載入器 | Fabric Loader 0.19.5 或相容新版 |
| 相依模組 | Fabric API 0.162.0+26.3 |

把本模組的遊戲 JAR 與相符的 Fabric API 放進遊戲實例的 `mods/`；多人伺服器與玩家端都要安裝相同版本。不要使用 `-sources.jar` 作為遊戲模組。目前只針對上述環境開發，其他 Minecraft 版本與載入器需另外移植。

官方專案是 [poplolioi11/yigua-minecraft](https://github.com/poplolioi11/yigua-minecraft)。從 [官方下載頁](https://github.com/poplolioi11/yigua-minecraft/releases) 取得對應版本的模組與原始碼，並用 [Issues](https://github.com/poplolioi11/yigua-minecraft/issues) 回報問題。GitHub 下載、Modrinth 與 Nexus Mods 的上架／審核各自獨立，以官方頁面的可下載版本及狀態為準；草稿或檔案上傳不代表平台核准。使用者指定暫緩 CurseForge，不再嘗試登入。

## 五步開始

1. 進入世界，收下首次贈送的「易經總覽書」。右鍵開書先看到**一頁目錄**。
2. 用 **1 枚銅錠製作 3 枚銅錢**，再把 3 枚錢合成三錢筮具；或用 **2 根竹子＋1 條線／1 個藤蔓**製作竹籌。任意 2 份纖維植物可製成線，準備 4 根竹子就能完成線綁竹籌。
3. 手持筮具右鍵，從角落面板選「開始起卦」或「練習起卦」。面板也能切換「傳統／自動／馬上」、文字／拖曳介面及眼前動畫。
4. 預設「自動」以約三秒動畫揭曉；「馬上」直接顯示聊天結果；「傳統」由你逐步分堆或投錢。三種方式都可練習，練習不產生效果、不寫圖鑑或冷卻。
5. 想查卦名、效果或來源，再從目錄進入「查六十四卦」「個人圖鑑」或「最近起卦」。每頁底部只有「目錄」，不必翻完長篇規則。

一頁目錄提供八個入口：傳統卜筮選項、多人與共享、起卦模式、閱讀規則、查六十四卦、個人圖鑑、最近起卦、太極工具。完整教學另放在「閱讀規則」，需要時再慢慢讀。操作細節見 [繁中入門手冊](docs/GETTING_STARTED.md)。

創造模式的 **「易經」分頁有 19 種物品**：五種單錢、五種三錢筮具、草籌、木籌、四種竹籌、兩本書與太極。`/yigua kit` 可取得一般筮具及書本，限創造模式。

## 玩法

- **傳統、自動、馬上**：錢幣與籌策各自保存起卦方式，預設自動。入口也可選擇右鍵先開面板或直接開始，與起卦方式分開設定。
- **文字或拖曳**：傳統三錢每爻投三枚，共十八次；拖一枚錢到投擲區放手，錢面由伺服器公平決定。傳統籌策可輸入左堆數，或逐根／框選後整批拖曳分堆，確認後由伺服器掛一、揲四、歸奇。每爻三變，共十八變；結果按照玩家實際分堆，完成後不重抽。兩種介面可中途切換並保留進度。
- **41 種效果與事件**：32 種一般效果，涵蓋移動、挖掘、攻擊屬性、護甲、幸運、重力、生命上限、水下活動及操作距離；另有 9 種隱藏稀有內容。動爻會決定額外效果，六爻特殊組合也有自己的卦局。
- **前五分鐘、後五分鐘**：有變卦時，前段使用本卦與動爻效果，後段切換為穩定變卦效果；沒有變卦則維持本卦十分鐘。以標準 20 TPS 的在線時間計算。
- **材質與環境**：木錢 0.5×、鐵錢 0.75×、褐銅錢 1×、銅綠錢 1.25×、金錢 1.5×；草籌 0.5×、木籌 1×、竹籌 1.5×。增益、減益都受倍率影響。八項環境因素各在 ±3% 內、合計在 ±10% 內微調強度，條件與權重留待探索。
- **個人收藏**：正式取得的本卦與次數依玩家隨世界保存；變卦、練習與閱讀不額外解鎖。原版「進度」分卦象與效果兩個頁籤，共 107 個節點。六十四卦依文王卦序排成八乘八網格，從乾至未濟；未取得也保留位置，亂序卜到即可解鎖。每卦保留自己的六爻圖示。
- **太極**：創造模式可直接取用；生存玩家完成全部卦象、32 個一般效果與 9 個隱藏成就後，獲得太極工具。它以約八秒緩轉的圖示呈現，可選六爻、選六十四卦、選 41 種效果或解除自身一卦狀態。選六爻或卦象會保存所選本卦、增加取得次數並更新最近卦象，標示為「太極指定」；直接選單一效果則另存效果紀錄，不增加卦象。太極效果不向群組共享，解除不抹去圖鑑或成就。

太極選六爻有變卦時，沿用本卦／變卦五加五分鐘規則；沒有變卦、選固定卦象或一般效果則約十分鐘，以玩家在線時間倒數。正向稀有狀態持續約兩分鐘，障路約一分鐘；雷光等即時事件仍依短演出時序結算。太極選特殊內容後，等待時間依所選事件期限計算。太極可在原狀態未結束前重新選擇，也可解除自身狀態與冷卻。以上時長以標準 20 TPS 計算。

0.2.1 的正向稀有狀態改為兩分鐘。五氣朝元帶來恢復、抗性、速度、挖掘加速、力量與循環五色氣流；三花聚頂帶來夜視、幸運、緩降與頭頂光花。已有同名或受保護的狀態會略過，聊天會告訴你實際新增幾項增益。五氣顯示附近非玩家生物過去三秒的真實位置虛影，三花顯示依目前移動和 AI 路徑推估的未來三秒；推估會隨生物改變行動而更新，並非保證未來；遇到未載入區塊就停止，不為預測載入新地形。

允許世界互動時，五氣可把原版生物移回近期安全位置或暫時返幼。五氣可回溯九種有界原版樹：橡木、樺木、杉木、櫻花、相思木、黑橡木、紅樹林、叢林木與蒼白橡木；支援天然枝幹與適用的四幹結構。非 persistent 冠葉作為辨識依據，仍無法百分之百區別自然與人工來源；無自然樹冠的木柱、合併多根、過大結構、水浸根與含資料方塊會拒絕或略過。成功或拒絕時會顯示短提示。成熟作物與莓果叢可回到幼苗、已結果瓜藤可回到幼藤、發光漿果藤可回到未結果狀態；草地、菌絲土、灰壤、泥土路、耕地、扎根泥土與粗泥可回到泥土。六種非機關銅材可倒退一個氧化階段，保留蠟層、方向及台階形狀；不處理容器、銅門或銅燈等機關。到期只復原仍屬自身的年齡與方塊；外部生長、上蠟或換材保留，不補生命、不改背包、不增加掉落物。

分海寬九格、含腳下至前方共十二格，從玩家深度開至每列水面；移動累積已開水道並保留後方，原兩分鐘期限到達時開始分批復原。乾地起效可等待入水，期限不重置；遇安全邊界或累積上限只停止新開路並告知，保留已有水道。障路生成期約一分鐘，每跨到新格或轉向便在前方升起，原地每 60 刻再起一輪。陸地每輪最多 7 格寬、3 格深、3 格高，共 63 格；水中沿 7×3 列從最深 128 格內的海床開始，每兩刻上升一層，直到玩家頭頂。可取代原版水、落葉、花草、藤蔓及其他無碰撞且可替換的植物方塊；不覆寫完整實體建築、方塊實體或既有回溯／分海持有位置。生成物按生態選材：沙漠、海洋、海灘用沙；寒冷地用雪塊；沼澤用泥坯；森林用青苔石；地獄用玄武岩；終界用終界石；其他地區用石頭。**落成的方塊永久保留，可正常挖掘與掉落；到期或太極解除只停止後續生成，不清除已建障壁。** 詳細限制見 [相容性說明](docs/COMPATIBILITY.md)。

「萬鳥朝拜」改名為「百鳥朝鳳」：兩分鐘鳳凰飛舞與像素振翅，按空白鍵上升、蹲下鍵下降，放開後緩降。飛行只採臨時移動與緩降，不開啟玩家的創造飛行權限；已具有飛行、鞘翅滑翔、漂浮等狀態時讓原有能力優先，重力或摔落傷害受保護時不啟用。

雲影、連續雷光與緩降光束呈現在當事玩家端，不改伺服器天氣；五氣與三花另有附近玩家可見的世界粒子。神秘內容不在遊戲書中預告觸發條件或機率；這批新增玩法仍待完整實機驗收。

正式起卦有 12000 個玩家在線遊戲刻的冷卻，標準 20 TPS 約十分鐘。等待期間仍可練習、閱讀或查看圖鑑；換筮具和重讀不會重抽或刷新效果。生命上限不是補血，燃燒時間不是免火，操作距離不是視距；效果範圍以遊戲內結果為準。

## 多人共享

**預設個人模式，送出與接收共享都關閉。** 從目錄的「多人與共享」自行建立或加入群組，再分別開啟送出／接收。每群最多 16 人，只有同維度、32 格內的同群成員符合分享條件。

來源玩家同意送出，接收玩家同意接收，才會分享仍在作用中的**一般正面效果**；同類只取最強，不把多位隊友的相同增益疊加。負面效果、整組罕見卦局與稀有事件不分享；接收不解鎖成就、不寫正式卦，也不刷新冷卻。離開範圍、離群、關閉接收或來源效果結束後，撤去本模組的共享修正。

## 整合包與伺服器設定

一卦新增自己的物品、效果與可移除屬性修正，不改武器基礎參數或世界生成。整合包可在 `config/yigua.json` 關閉卦象效果、稀有事件或共享，也可用 `protected_attributes`、`protected_effects` 指定要讓其他模組優先的項目。

`world_changes_enabled` 控制分海、障路與五氣攻擊回溯等世界互動。沒有填此欄位時，**獨立伺服器預設關閉，單人整合伺服器預設開啟**。本模組沒有對所有領地模組共通的權限掛鉤；服主應依自己的領地與整合包設定決定是否開啟。小範圍與復原紀錄不等於領地權限保障。

本模組無法自動讀取所有第三方設定，也不宣稱支援任意整合包。保護清單、資料包入口與設定範例見 [入門手冊](docs/GETTING_STARTED.md#相容性保護與世界設定)，新版互動的界線見 [相容性說明](docs/COMPATIBILITY.md)，實際測試組合見 [驗收紀錄](docs/VALIDATION.md)。

## 自行建置

使用 Java 25，在專案根目錄執行：

```sh
./gradlew build
python3 tools/verify_data.py
```

使用 `build/libs/` 中不帶 `-sources` 的模組 JAR。第一次建置需要下載工具與相依套件；建置、自測與資料解析不等同實機、多人或整合包驗收。
