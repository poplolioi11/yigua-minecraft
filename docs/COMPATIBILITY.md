# 一卦相容性與世界互動界線

此檔說明 **0.2.1 公開測試版**。最新完整建置與自測通過：10 秒、28 項工作（26 項執行、2 項沿用）。最新原生單人測試於 2026-10-12 06:02（臺灣時間）完成 12 個案例／537,671 項斷言，涵蓋永久障路、六種真正生成樹／方塊前態，以及鳳翼升降、緩降、外來能力優先與到期；原世界、玩家狀態與測試按鍵已復原。這是載入 13 個外部模組的 IntegratedServer 本機記憶體連線，不能代替最新真正 TCP 或獨立伺服器驗收。較早 10 案例／20,900 項斷言保留為上述修改前基線。獨立移動牛 fixture 已確認 FUTURE／PAST 分離虛影的原生 GPU 畫面，鳳翼第一人稱 GPU 畫面已見雙翼與鳳凰；此輪不是獨立伺服器或真正 TCP 多人驗收。[0.2.0](https://github.com/poplolioi11/yigua-minecraft/releases/tag/v0.2.0) 的真正 TCP 結果保留為歷史基線。受測組合與界線見 [VALIDATION.md](VALIDATION.md)。下載及各平台狀態以官方頁面為準。

## 遊戲與模組版本

Minecraft Java 26.3、Java 25、Fabric Loader 0.19.5、Fabric API 0.162.0+26.3；主機與所有玩家端安裝同一版一卦。不同 Minecraft 版本與載入器需另行移植。進度排版 mixin 只調整 `yigua:hexagrams/root` 的六十四卦，不改其他進度樹；新增自然水流攔截也只限分海持有的空氣位置，沒有替換全域流體模擬。

## 屬性、原版狀態與保護清單

一般卦象使用自己的識別名稱與可撤回修正，不修改特定武器的基礎傷害。第三方原有屬性修正與藥水狀態保留；各模組仍可共同影響最終計算。一般十分鐘、變卦前後五分鐘的規則沒有改動。

`config/yigua.json` 可用 `protected_attributes` 排除原版屬性，或以 `protected_effects` 排除一般 profile、特殊事件 ID 與稀有增益的完整原版狀態 ID。原版狀態例如 `minecraft:speed`、`minecraft:haste`；一般一卦效果例如 `travel`、`strength`。設定範例見 [玩家入門](GETTING_STARTED.md#相容性保護與世界設定)。

神光、五氣與三花共用原版增益的檢查：只補上**當下尚無同名且符合保護清單**的原版 beneficial 狀態，不加入第三方狀態。神光另可補一般一卦正面狀態。非即時正向狀態維持 **2400 刻，正常 20 TPS 約兩分鐘**；原版即時狀態只當場作用一次。

| 稀有狀態 | 可授予的原版增益，皆為第一級 |
| --- | --- |
| 五氣朝元 | 恢復、抗性、速度、挖掘加速、力量 |
| 三花聚頂 | 夜視、幸運、緩降 |

實際新增數量由聊天揭曉，既有或受保護項目會略過。除了狀態本身的屬性修正，也檢查挖掘、跳躍、海豚、水下、呼吸、火焰及緩降等原版直接公式的保護項目；這不能讀取所有第三方隱含限制。神光方位效果只在原版方位條件與保護設定允許時貢獻移速，已有一般方位效果不重新套用。

取消只撤回仍可確認為本模組授予的精確實例；同名狀態若已被他處延長、改強度或替換，會保留。無法重建來源的存檔狀態不假認為自有。多人共享仍只接受一般正面結果，不分享整組罕見卦局或神秘事件。

## 生物時間虛影

只向持有狀態的玩家顯示 **32 格內最多 24 個非玩家生物、各最多 6 個樣本**。五氣的過去軌跡來自伺服器每 10 刻實際位置記錄，最多回看 60 刻；三花的未來軌跡是目前速度及 AI 路徑的 10–60 刻推估，遇到障礙或生物改變行動會更新，不是預知伺服器之後真正發生的事。初開五氣時沒有尚未記錄的歷史可看。未來每個步距的身體範圍與眼位射線先枚舉所需區塊，只用既有已載入區塊；任一缺漏即停止後續推估，再做原生碰撞／射線檢查，不為預測載入或生成地形。

原版可用的生物主模型以獨立 `EntityRenderState` 半透明提交；不修改活體的可見性、位置、AI 或模型狀態。自訂渲染器或不適用模型降級為像素形體輪廓，並非完整自訂生物模型。玩家與對當事者不可見的生物不顯示；核對實體 ID、UUID 與類型後才呈現，避免舊 ID 被重用後畫錯生物。死亡、換世界、斷線、解除與停止更新會撤回虛影。

五色氣流與三朵光花在兩分鐘內循環，另有受控世界粒子；不每刻累積永久物件。正式 PAST／FUTURE 封包、獨立原生模型 state 及實際 submit 委派已有原生驗證；獨立移動牛 fixture 另確認兩模式各六筆分離虛影、最大跨度 5 格與原生 GPU 畫面。粒子會部分遮擋；此為原版牛的指定場景，未驗任意渲染模組或全部生物。

## 天空與雷光

黑雲、雲散、光束與雷光由當事客戶端呈現，不改伺服器天氣。黑雲使用世界空間的 121 組雲簇及畫面疊層，地形以正常深度測試遮擋。神光演出維持 120 刻，光束由 32 格高度於 100 刻內下降；演出結束不代表兩分鐘增益結束。

天雷六道畫面依時序呈現，約第 77 刻才進行一次原版傷害判定；不建立會點火、氧化銅或觸發避雷針的真正世界閃電實體。傷害尊重拒絕傷害、無敵與不死圖騰機制。死亡時黑雲可延續至原演出 160 刻結束，重生後清除。較早開發快照的局部原生測試已確認六道與一次傷害，不能代替最新完整回歸。

## 世界變更、永久障路與復原

`world_changes_enabled` 控制分海、障路及五氣攻擊回溯。未填時，**獨立伺服器預設關閉、單人整合伺服器預設開啟**；關閉不移除五氣／三花時間虛影或允許的增益。`effects_enabled`、`special_events_enabled` 與事件保護項目也可停用功能。改方塊與生物的互動共用原生世界權限檢查；沒有所有領地或 claim 模組共通的掛鉤，服主仍需依自己的保護規則決定是否開啟。

分海、方塊回溯與障路待放置位置互相排除已占用的位置。分海／回溯的待復原位置繼續保留；新障路落成後直接按普通永久方塊保存，沒有可撤回的障路 journal。較早 v1 暫時障路日誌只供相容復原，不用來儲存新永久建造。只操作已載入、安全範圍內的資料，不為事件強制生成區塊。復原前檢查狀態是否仍屬自身；外部替換保留。直接寫成完全相同狀態的外部變更仍可能無法辨識，這不是完整世界版本控制。

### 分海

**九格分海在最新 12 案例原生套件通過步行／轉向／到期及復原，整輪亦通過。** 寬九格，含腳下至前方共十二格，每列從玩家所在深度開到該列水面。轉向及移動累積已開水道、保留後方，原定 **兩分鐘**到期便停止擴張、開始分批復原；移動不延長總期限。合法乾地起效會保留session等待進水，總期限也不重置；未載入／不安全列只略過並告知，不強制生成地形、不收回已有水道。低頭可觀察露出的水道地面。此前五格寬固定視窗的原生安全取消與世界復原紀錄保留，不代替新版驗收。

累積硬界為 **32,768格、32區塊、8MiB日誌**。達方塊或區塊上限只停止新擴張並告知，已有水道保留至期限；最大方塊數與最長合法座標自測的日誌為 **4,108,369 bytes**，小於8MiB。每刻候選水位掃描至多2,048格、新開路至多512格、所有權巡查至多256格、復原至多512格。到期／解除可能跨多刻完成復原；未載入或保護拒絕的位置保留紀錄待安全復原，不能視為全部方塊在到期當刻已還原。

僅攔截原版自然水流回灌**本模組持有且仍為空氣**的位置，不攔玩家桶水的直接放置，也不攔第三方流體。任何重新放入的方塊或水，包括與原水相同LEVEL，巡查時都會撤權並保留，不再清除。失去所有權或保護拒絕時不攔截；到期／復原中的自有空氣仍在許可下攔截回灌，直到該格復原完成才釋放，避免分批還原前被水流提早覆寫。水位復原後，原版流體仍可正常更新。

### 永久生態障路

障路生成期約一分鐘，每跨到新格或轉向便在前方升起，原地每 60 刻再起一輪。陸地每輪最多 7 格寬、3 格深、3 格高，共 63 格；水中沿 7×3 列從最深 128 格內的海床開始，每兩刻上升一層，直到玩家頭頂。可取代原版水、落葉、花草、藤蔓及其他無碰撞且可替換的植物方塊；不覆寫完整實體建築、方塊實體或既有回溯／分海持有位置。生成物按生態選材：沙漠、海洋、海灘用沙；寒冷地用雪塊；沼澤用泥坯；森林用青苔石；地獄用玄武岩；終界用終界石；其他地區用石頭。**落成的方塊永久保留，可正常挖掘與掉落；到期或太極解除只停止後續生成，不清除已建障壁。**

採原版方塊與區塊存檔，落成後不保留暫時所有權；可被玩家及其他模組正常修改。待放置佇列有界，尚未落成的位置仍須逐格重新核對原狀態、權限、附近實體及互斥預約；外部方塊變更或拒絕許可會取消該位置。永久地形不是世界復原功能，世界備份須包含完整原版區塊。

### 五氣攻擊回溯

只對適用的原版非玩家生物做短距安全位置回溯或暫時返幼，不補生命、不還原背包、不產生戰利品。位置回溯是當下的一次安全移動；暫時年齡另外記錄並在期限／解除時復原。年齡標記以持久 attachment 隨生物保存；若年齡已被外部改動、實體類型或 UUID 不符，放棄所有權，不強行重設。需復原但當下權限拒絕時保留紀錄等待處理。

五氣可回溯九種有界原版樹：橡木、樺木、杉木、櫻花、相思木、黑橡木、紅樹林、叢林木與蒼白橡木；支援天然枝幹與適用的四幹結構。非 persistent 冠葉作為辨識依據，仍無法百分之百區別自然與人工來源；無自然樹冠的木柱、合併多根、過大結構、水浸根與含資料方塊會拒絕或略過。成功或拒絕時會顯示短提示。成熟作物與莓果叢可回到幼苗、已結果瓜藤可回到幼藤、發光漿果藤可回到未結果狀態；草地、菌絲土、灰壤、泥土路、耕地、扎根泥土與粗泥可回到泥土。六種非機關銅材可倒退一個氧化階段，保留蠟層、方向及台階形狀；不處理容器、銅門或銅燈等機關。

單次樹群與全部方塊紀錄合計最多 1,024 格、32 組，單樹檢查最多 8,192 個已載入座標，回溯日誌最多 1 MiB。只檢查原版明確白名單狀態；完整實體、容器及外部模組方塊不作前態轉換。自有樹苗／幼苗／回溯方塊不能被挖成重複掉落物。自然重新生長、外部上蠟、換材或其他改動後失去精確所有權，到期保留外來狀態；樹苗已長成新樹時釋放整棵回溯，避免重建另一份樹。直接改成完全相同狀態仍可能無法辨識。

世界備份應保存完整世界存檔，包含 `data/yigua/`、區塊與生物資料。停止程序或毀損復原紀錄時，不以刪除紀錄冒充成功，未完成復原會阻止新互動。最新完整建置與自測通過，永久障路、六種真正生成樹／方塊前態及鳳翼原生套件共 12 案例／537,671 項斷言通過並復原；這不構成任意世界、獨立伺服器或領地權限保障；實際範圍以 [VALIDATION.md](VALIDATION.md) 為準。


## 百鳥朝鳳與飛行優先

「萬鳥朝拜」改名為「百鳥朝鳳」：兩分鐘鳳凰飛舞與像素振翅，按空白鍵上升、蹲下鍵下降，放開後緩降。飛行只採臨時移動與緩降，不開啟玩家的創造飛行權限；已具有飛行、鞘翅滑翔、漂浮等狀態時讓原有能力優先，重力或摔落傷害受保護時不啟用。到期或解除會停止振翅並轉入有界安全緩降；現有能力來源會保留，不改伺服器 `allow-flight`，不切遊戲模式，也不把此效果分享給群組。
