# 一卦 Minecraft 入門手冊

本手冊說明 **0.2.1 公開測試版**，環境為 Minecraft Java 26.3、Java 25、Fabric Loader 0.19.5 與 Fabric API 0.162.0+26.3。完整建置及載入 13 個外部模組的原生單人 12 案例通過，鳳翼飛行與分離時間虛影已有實際遊戲確認；最新真正 TCP 與獨立伺服器仍未驗收。先前 0.2.0 多人基線與完整範圍見 [驗收紀錄](VALIDATION.md)。[官方下載頁](https://github.com/poplolioi11/yigua-minecraft/releases) 與各平台頁面決定目前可下載版本、上架及審核狀態。

## 安裝與第一本書

1. 準備 Minecraft Java 26.3 的 Fabric 遊戲實例，使用 Java 25。
2. 將本模組 JAR 與相符的 Fabric API JAR 放入該實例的 `mods/` 資料夾。請使用編譯後的模組檔，不要放入 `-sources.jar`。
3. 多人遊戲時，伺服器與玩家端都安裝相同版本的本模組與 Fabric API。
4. 啟動並進入世界。玩家首次進入這個世界時，會收到「易經總覽書」與提示訊息；背包滿時，書會掉落在身旁。
5. 把總覽書拿在手上按右鍵，先看到一頁操作目錄；想讀詳細教學，再選「閱讀規則」。

初次贈書是每位玩家、每個世界一次，並不是每次登入都贈送。書本遺失後可重新合成；`/yigua menu` 也能提供入口。若指令先給你一本書，拿到手上再右鍵閱讀。

遊戲內書本的作者欄標示 `poplolioi11`；規則冊保留簡短 MIT 開源說明與來源連結。

## 製作筮具與書本

以下合成都為**不定形配方**，材料無須固定格位。三錢、草籌、木籌與原色竹籌都能使用背包的 2 × 2 合成格製作，無須工作臺。

| 製作物 | 材料 | 產量 |
| --- | --- | --- |
| 木錢 | 任意 1 塊木板 | 3 枚木錢 |
| 鐵錢 | 1 枚鐵錠 | 3 枚鐵錢 |
| 銅錢 | 1 枚銅錠 | 3 枚銅錢 |
| 金錢 | 1 枚金錠 | 3 枚金錢 |
| 銅綠錢 | 1 個氧化銅方塊 | 27 枚銅綠錢 |
| 三錢筮具 | 3 枚相同材質的錢 | 1 組同材筮具 |
| 線 | 任意 2 份纖維植物，可混用 | 1 條 |
| 草籌筮具 | 任意 2 份甘蔗、高草或大型蕨（可混用）＋1 條線 | 1 組 |
| 木籌筮具 | 2 根木棒＋1 條線 | 1 組 |
| 竹籌筮具（線綁） | 2 根竹子＋1 條線 | 1 組 |
| 藤綁竹籌筮具 | 2 根竹子＋1 條藤蔓 | 1 組 |
| 易經總覽書 | 1 本書＋1 枚銅錢 | 1 本 |
| 個人卦象圖鑑 | 1 本書＋1 根竹子 | 1 本 |

木、鐵、褐銅、銅綠與金各有單錢和三錢筮具；三錢合成須使用同材的三枚錢。銅綠錢使用**氧化銅方塊**製作，1 方塊對應 9 枚銅錠，因此產出 27 枚錢。

纖維植物包含竹子、甘蔗、藤蔓、蕨、短草與樹葉。例如 2 根竹子、2 根甘蔗或 2 個樹葉都可製作 1 條線，也可混用兩種材料。因此準備 **4 根竹子**，先用其中 2 根製線，再用其餘 2 根與線合成筮具，就能開始竹籌起卦。

草籌呈淡黃綠，木籌呈木棕；它們與竹籌都採蓍草法。草、木、竹的材質會影響遊戲效果強度，詳見下方倍率表。

原色線綁與藤綁竹籌都可放入**熔爐或營火烤製**，各自變成對應的烤製竹籌，保留原綁材；烤製後不能再烤回原色。線綁保留原色、藤綁呈淡綠，烤製線綁呈暖棕、烤製藤綁呈深橄欖棕。四種竹籌彼此的差異是外觀，**不改變起卦機率、效果強度、冷卻或圖鑑規則**。

筮具可重複使用，起卦不消耗錢或籌。自動起卦在開始時確定正式結果與效果，動畫只延後揭曉；離線、死亡或換維度會取消呈現，結果仍會保存。手動起卦則要完成六爻後才提交結果，未完成的取消規則見「親手逐步起卦」。揭曉後以聊天顯示結果，可用 `/yigua result` 自行閱讀結果書。

創造模式開啟物品欄後，選擇 **「易經」分頁**。分頁圖示是銅錢，內有五種單錢、五種三錢筮具、草籌、木籌、四種竹籌、易經總覽書、個人卦象圖鑑與太極，合計 **19 種物品**。若分頁太多，可按 Page Down 翻到下一組分頁，再選「易經」。也可使用物品搜尋，輸入 **「三錢」「草籌」「木籌」「竹籌」「木錢」「鐵錢」「金錢」「銅錢」或「銅綠」** 找到對應物品；原版「工具與實用物品」分頁也保留這些入口。

若要直接開始測試，可輸入 `/yigua kit`，取得測試筮具、總覽書與圖鑑；此指令僅限創造模式。

## 起第一卦

1. 手持三錢筮具、草籌、木籌或任一竹籌筮具，右鍵打開角落工具面板。
2. 面板可循環切換「傳統／自動／馬上」、文字／互動拖曳介面與眼前動畫，再選「開始起卦」或「練習起卦」。只看面板或關閉不生成結果。
3. 預設「自動」播放約三秒的六爻呈現。「馬上」略過動畫，直接在聊天揭曉；正式效果與冷卻規則相同。「傳統」先逐步分堆或投錢，完成六爻才提交結果。
4. 聊天列出本卦、動爻、變卦與實際效果。要讀經文，再用目錄的「最近起卦」或 `/yigua result`，不會自動跳出結果書。

三錢與籌策**各自保存起卦方式**；角落切換只改手上這種方法。目錄的三模式快捷可同時設定兩種。預設兩種都是自動，傳統玩法關閉。起卦呈現偏好保存在本機，圖鑑、群組與共享選擇隨世界保存。

右鍵入口是另一項設定：`/yigua-mode button` 先開面板，`/yigua-mode direct` 依所選方式直接開始正式起卦。「直接入口」不等於「馬上」；直接入口也可以開始自動動畫或傳統操作。

眼前筮具像素動畫可在面板切換，也可用 `/yigua-animation on`／`off`。關閉此選項會停止中央放大筮具動畫；右側六爻進度與既有細小粒子仍保留，不改卦象、冷卻或效果。錢幣與籌策的材質、綁材與烤製色彩也會呈現在動畫與手動介面。

聊天中的本卦是原六爻構成的卦；六或九為動爻，只翻轉動爻便得到變卦。沒有動爻時，卦象不變。生成順序**由下往上**，初爻最先、上爻最後；書本畫卦時由上爻往下列，兩者用途不同。

## 傳統：文字或互動拖曳

從目錄選「傳統卜筮選項」，或用 `/yigua-ritual coins on`、`/yigua-ritual yarrow on` 開啟對應方法。`off` 使該方法回到自動。`/yigua-ritual-mode traditional`／`auto`／`instant` 可同時設定兩種方法。

傳統玩法提供**文字**與**互動拖曳**；預設選互動拖曳，但不會因此自動開啟傳統玩法。可在起卦面板或傳統操作頁切換，也可用 `/yigua-ritual-ui text`／`interactive`。切換介面保留目前爻、變次與已提交結果，不重新開始或重抽。

### 三錢逐枚投擲

互動介面：拖起一枚同材質錢幣，移到「放手投擲」區後放開；放在區外不投錢。也可按「投擲一枚」，文字介面同樣提供此按鈕。畫面標示「三錢法・逐枚記錄」，左側顯示本爻「已投 0/3」及剩餘枚數。每枚公平取二或三，**錢面由伺服器決定**，不能靠拖曳方向指定。

本模組固定約定 **字面（陰）＝2、背面（陽）＝3**，每枚旁顯示面名與數值。三枚相加得到 **6 老陰、7 少陽、8 少陰、9 老陽**；6／9 是動爻，7／8 不變。例如 `3 + 2 + 2 = 7` 為少陽。每三枚合成一爻，從初爻到上爻共六組、十八枚；畫面保留上一爻的三枚值、合計與判讀，直到下一組完成，右側亦保留已成六爻與進度。

《卜筮正宗》〈以錢代蓍法〉以字／背的三枚組合區分陰陽及動靜，並由下往上裝卦；本模組的二／三加總是等價的遊戲呈現約定。傳統常將三枚一起擲，本互動選項依序投擲與記錄單枚，不能把逐枚操作稱為唯一古法。[原文來源](https://www.shidianguji.com/zh/book/HY1439/chapter/1m70sj2411nvn)。

### 籌策十八變

每爻由四十九策開始。互動介面把可見的竹籌、木籌或草籌拖到另一堆；按住 **Shift 拖曳框選多根**後，再拖任一選中的籌策，可以整批移動。兩堆的根數隨實物移動更新，**不是滑桿換算或重新隨機分堆**。

確認前可來回調整。左堆至少一根，右堆至少兩根，以保留掛一後的一根。按「確認分堆・掛一揲四」才提交實際左堆數，之後由伺服器掛一、揲四、歸奇並顯示餘數。文字介面則輸入左堆數後確認。

第一變左堆範圍為 1 至 47，後續上限隨餘策改變。兩堆除四的餘數若為零，按四策歸奇；第一變收去五或九策，第二、三變收去四或八策。每爻三變，最後餘策除四得到六、七、八或九；下一爻重新取四十九策，共十八變。

玩家實際分堆決定結果，完成後**不再抽卦**。人工分堆會改變卦象分布；傳統機率表是隨機模型參考，不保證人工選數符合該分布。

完成六爻後才記錄正式結果、套用效果與開始冷卻，再播放短揭曉。取消、離線、死亡、換維度或更換原手別筮具，會取消未完成流程；未完成不記圖鑑、不套效果、不刷新冷卻。傳統練習同樣不寫正式紀錄。

## 練習與冷卻

在面板模式下，手持筮具右鍵開面板；同樣可先選「傳統／自動／馬上」，再按「練習起卦」。若目前採直接模式，可先用 `/yigua-mode button` 切回面板。練習會生成另一個結果，並將遊戲效果標示為示例；**不實際套用效果、不收入圖鑑、不更新最近的正式結果，也不新增或刷新冷卻**。

每次正式起卦會開始 **12000 個玩家在線遊戲刻**的冷卻。標準 20 TPS 約為 10 分鐘；伺服器延遲時，實際時間可能較長。玩家離線時停止倒數。

冷卻尚未結束時，不能生成新的正式卦；換另一種筮具也不會重抽、增加圖鑑計數或刷新效果。用 `/yigua result` 或書內「最近結果」入口重讀原本的正式結果。等待期間仍可從工具面板練習、閱讀總覽與查看圖鑑。用 `/yigua status` 查看蒐集進度與剩餘在線冷卻時間。

## 多人：預設個人，自行開啟共享

從目錄進入「多人與共享」。**送出與接收預設都關閉**，沒有加入群組也可照常個人起卦。

1. 一位玩家選「建立自己的群組」，取得八碼群組邀請碼。
2. 想加入的玩家自行輸入 `/yigua group join CODE`，把 `CODE` 換成邀請碼。每群最多 16 人；加入不會自動開啟共享。
3. 來源玩家開啟「送出共享」，接收玩家開啟「接收共享」。只有雙方各自同意、同群、同維度且相距 32 格內，才分享一般正面效果。
4. 想停止時，關閉對應開關、離群或離開範圍。`/yigua group leave` 離群，`/yigua group status` 查看目前設定。

分享來源須仍然在線、存活且效果實際作用中。**同類只取最強**，不把多人的相同增益疊加，也不與自身同類增益重複相加。負面效果、整組罕見卦局與稀有事件不分享；方向性效果含減益，也不列入共享。

接收不寫正式起卦、不解鎖圖鑑或成就、不刷新冷卻。來源效果到期、被清除、死亡或離線後撤去共享；自身和其他模組的效果各自保留。伺服器可統一停用共享，個人開關不能繞過服主設定。

## 全收集後的太極

太極沒有一般合成配方。創造模式可從「易經」分頁取用；生存玩家必須先收集 **64 個正式本卦**，並完成 **64 個卦象成就、32 個一般效果成就與 9 個隱藏挑戰**，才由系統贈送一次。單純拿到物品不等於取得使用資格。

符合資格但遺失太極時，可用 `/yigua taiji claim` 再領；仍須通過資格核對，而且目前背包沒有太極。太極圖示約八秒緩慢轉一圈。

右鍵太極打開選擇介面：

- **選六爻**：逐爻切換六、七、八、九，再確認組合；初爻在下。保存所選本卦、增加該卦取得次數並更新最近卦象，結果標示為「太極指定」，有變卦時沿用前五分鐘、後五分鐘的兩段效果。
- **選六十四卦**：挑選卦名，確認套用該卦的基礎效果。使用沒有動爻的固定卦，同樣保存本卦、增加取得次數並更新最近卦象；不偽裝成隨機起卦。
- **選遊戲效果**：挑選 32 種一般效果或 9 種已解鎖特殊內容，共 41 種，確認後套用；危險項目需另確認。創造模式可查看特殊內容，生存模式須先取得相應成就。單一效果另存為指定效果紀錄，不增加卦象圖鑑或取得次數，也不把它套上先前的卦名。
- **解除一卦狀態**：停止自己的未完成流程、動畫、自有一卦效果與冷卻，撤回當下共享修正並關閉接收共享。想接收時可在書中重新開啟。

選固定卦象或一般效果約維持十分鐘，以玩家在線時間倒數；選六爻有變卦時則為五加五分鐘。正向稀有狀態約兩分鐘，障路的生成期約一分鐘、落成方塊永久保留；雷光等即時事件依短演出時序結算。太極選特殊內容後，起卦等待按事件期限計算。時長以標準 20 TPS 計算；暫時環境互動另按世界時間復原，不因玩家離線延長。

太極可在效果或冷卻未結束前重新選擇，替換自己的現有一卦狀態。所有太極選擇都不向群組共享。解除不抹去圖鑑或成就，也不移除其他模組或藥水的效果；伺服器的效果保護及世界設定依然有效。

## 三錢與蓍草法怎麼不同

三錢法把每枚公平錢的兩面記為二與三，三枚相加得到六、七、八或九，一共生成六次。草籌、木籌與竹籌則替代傳統蓍草材料；自動模式採用五十策去一、四十九策起算、每爻三變的理想化餘數模型，手動模式依玩家實際分堆逐變計算。教學書說明分二、掛一、揲四、歸奇，以及六爻共十八變。

兩種自動方法的爻值機率不同；蓍草模型不是把所有分堆位置當成均勻抽樣。不同材質的三錢共用三錢法機率，草、木、竹籌共用蓍草法；手動蓍草由分堆數決定，不假設玩家均勻選數。

| 爻值 | 名稱 | 爻與變化 | 三錢法 | 蓍草理想化模型 |
| --- | --- | --- | --- | --- |
| 六 | 老陰 | 陰爻，動而變陽 | 1/8 | 1/16 |
| 七 | 少陽 | 陽爻，不動 | 3/8 | 5/16 |
| 八 | 少陰 | 陰爻，不動 | 3/8 | 7/16 |
| 九 | 老陽 | 陽爻，動而變陰 | 1/8 | 3/16 |

## 收集個人圖鑑

手持「個人卦象圖鑑」按右鍵，或手持總覽書／筮具輸入 `/yigua atlas`。圖鑑列出六十四卦的「已／未」狀態、完成度與每一卦正式取得的次數。

只記錄**正式起卦的本卦**。變卦不會同時解鎖；閱讀某一卦、練習起卦與冷卻期間重讀也不會解鎖或增加次數。已收集的卦再次正式出現時，該卦次數會增加，已發現總數維持不變。

圖鑑紀錄屬於玩家，依 UUID 隨世界保存，不是寫在那一本書裡；換書或把書交給其他人不會轉移收集紀錄。世界備份須保留完整的 `data/yigua/` 資料夾；其中的 `players.json` 保存圖鑑、正式次數、最近結果與冷卻，其餘自有紀錄也可能供短時環境互動復原使用。

### 原版成就介面

進入世界後，可在原版「進度」介面查看 **「一卦・六十四卦」**與 **「一卦・遊戲效果」**兩個頁籤。共 107 個節點：64 個本卦、32 個一般效果、9 個隱藏挑戰，以及兩個頁籤的根節點。六十四卦依文王通行卦序排成 **8 × 8 網格**：第一排乾至比，第二排小畜至豫，依此由左至右、由上至下排列，最後為未濟；拖曳可查看後續各排。尚未取得的卦也保留位置；每卦有自己的六爻圖示，初爻在下、上爻在上。書本圖鑑仍保留取得次數。

## 卦象如何影響遊戲

本版有 64 卦基礎規則、9 則動爻覆寫與用九／用六兩則特別規則。共有 **32 種一般效果**與 **9 種隱藏稀有內容**，合計 41 種效果／事件，材質倍率與強度等級不另計種類；另有沒有增益／減益的中性結果。基礎效果如下，材質、罕見卦局與起卦環境會再調整實際強度。

| 類型 | 基礎幅度與範圍 |
| --- | --- |
| 移動速度 | 增加或降低 10% |
| 挖掘速度 | 增加或降低 10% |
| 攻擊傷害 | 增加或降低 1 |
| 護甲 | 增加或降低 1 |
| 攻擊恢復速度 | 增加或降低 10% |
| 幸運 | 增加或降低 1；只影響含幸運判定的戰利品 |
| 下落加速度 | 降低或增加 10%；也會影響跳躍 |
| 摔落傷害 | 降低或增加 10% |
| 水下耗氧 | 原版實際耗氧時，額外增加 10% 消耗 |
| 生命上限 | 增加或降低 2；不直接補血 |
| 跳躍力 | 增加或降低 10% |
| 擊退抗性 | 增加或降低 0.1，為加值 |
| 燃燒時間 | 縮短或延長 10%；仍會受到火焰傷害 |
| 方塊操作距離 | 增加或降低 0.5 格；不改視距 |
| 水下耗氧抵抗 | 增加 1，沿用原版耗氧判定，仍可能耗氧 |
| 水下挖掘速度 | 增加或降低 10% |
| 生物互動與近戰距離 | 增加 0.5 格 |
| 順方 | 實際向西南移動時加速 10%，向東北移動時減速 10%，其他方向無加減速 |

「生機／衰耗」調整可容納的生命上限，不會直接回復目前生命；「避灼／餘燼」調整燃燒持續時間，不提供免火。方塊與生物的操作距離影響近距離操作，不擴大視野；「順方」按實際水平移動方向判定。擊退抗性使用 0.1 的加值，不把它寫成速度類的百分比修正。

三錢與籌策的材質會調整**效果強度**。單看材質，倍率介於基礎的 0.5 至 1.5 倍，最大差異為 ±50%：

| 筮具材質 | 效果倍率 | 基礎移速 +10% 時 |
| --- | --- | --- |
| 木錢 | 0.5× | +5% |
| 鐵錢 | 0.75× | +7.5% |
| 褐銅錢（原銅錢） | 1× | +10% |
| 銅綠錢 | 1.25× | +12.5% |
| 金錢 | 1.5× | +15% |
| 草籌 | 0.5× | +5% |
| 木籌 | 1× | +10% |
| 竹籌（全部四種外觀） | 1.5× | +15% |

倍率同時作用於增益與減益；例如金製三錢遇到基礎移速 −10% 的卦，單看材質會採 −15%。中性基礎效果不因材質產生加減值；有動爻時仍可能追加效果。材質不改變同一方法的爻值機率、效果時長、正式冷卻或圖鑑計數規則。舊存檔中的既有正式卦保留原先紀錄，不因新材質設定重算。

一般卦的效果選取依序是：

1. 乾卦六爻全動使用用九，坤卦六爻全動使用用六。
2. 其餘情況，檢查全部動爻是否有對應覆寫；優先序較高者優先，同優先序時爻位較高者優先。
3. 沒有符合的覆寫時，使用本卦基礎效果。這一步先決定主要效果或中性結果，再按下方的動爻規則選取追加效果；罕見卦局沿用其組合規則。

九則覆寫是頤上九、蹇九三、乾上九、節初九、節九二、未濟六三、無妄六三、履九四與大過上六。這是人工編排的遊戲規則，不是搜尋「吉」「凶」或「利涉大川」字串就自動判斷，也不自稱唯一或正統的傳統占斷方法。

### 動爻的追加效果

一般卦的動爻會實際影響遊戲效果：

| 動爻數 | 效果組成 |
| --- | --- |
| 0 | 主要效果或中性結果，沒有追加 |
| 1–2 | 主要效果之外，最多追加一項 |
| 3–5 | 主要效果之外，最多追加兩項 |
| 6 | 沿用六爻全變的罕見卦局規則 |

追加候選依動爻爻位、六或九，以及本次主要效果的正負搭配；完整六爻確定後結果就固定，不另重抽，也不重複相同 profile。追加效果同樣按材質與起卦環境縮放，效果時長維持原規則。這是遊戲中的爻位映射，與原文解釋分開呈現，並非替 384 爻逐一完成傳統占斷考證。

武英殿版原文包含 384 條爻辭與用九／用六；另封裝《伊川易傳》64 卦的卦辭、程傳初錄快照與局部校核紀錄，書中提供卦辭及程傳短節錄。這不是完整經傳，也未完成全文逐字影像二校；初錄中的疑字與卷次問題仍保留說明。原文與效果分開呈現，數值屬遊戲改編。來源、缺損說明與用辭的獨立頁碼缺口，見 [PROVENANCE.md](../PROVENANCE.md)。

### 罕見卦局

六爻構成特別組合時，可能出現「否極泰來」「泰極否來」「群龍無首」「利永貞」或「六爻皆變」等罕見卦局，帶來較強的 2–3 項組合效果。聊天與結果書會告訴你本次遇到的卦局與效果。這些是依實際六爻決定的遊戲改編。

正式起卦也可能遇見天空光影或稀有環境互動，神秘內容留待玩家探索。0.2.1 正向稀有狀態約兩分鐘，障路的生成期約一分鐘、落成方塊永久保留；雲影與光束保留地形遮擋，天空視覺只作用於當事玩家，不改全世界天氣。六道雷光演出後只結算一次原版傷害。遊戲書不公開神秘事件的觸發條件或機率。

五氣朝元與三花聚頂會持續呈現五色氣流／頭頂光花，並加入符合保護設定、當下沒有的原版增益。五氣的五種增益是恢復、抗性、速度、挖掘加速與力量；三花的三種是夜視、幸運與緩降，皆為第一級。聊天會顯示實際新增數量，並提醒已存在或受保護的項目已略過。

時間虛影只顯示 **32 格內最多 24 個非玩家生物、各最多 6 個影像**。五氣每半秒留下一筆真實位置，最多看過去三秒，剛開始尚無完整歷史；三花依目前速度與 AI 路徑推估未來三秒，生物轉向、受阻或換目標後會更新；身體範圍或眼位射線涉及未載入區塊時停止後續推估，不為預測載入或生成地形。原版可用模型以半透明虛影呈現；不適用的自訂渲染器改為像素形體輪廓，不修改活體狀態。玩家不會出現在軌跡裡。

世界互動允許時，五氣下攻擊原版生物可回到近期安全位置或暫時返幼。五氣可回溯九種有界原版樹：橡木、樺木、杉木、櫻花、相思木、黑橡木、紅樹林、叢林木與蒼白橡木；支援天然枝幹與適用的四幹結構。非 persistent 冠葉作為辨識依據，仍無法百分之百區別自然與人工來源；無自然樹冠的木柱、合併多根、過大結構、水浸根與含資料方塊會拒絕或略過。成功或拒絕時會顯示短提示。成熟作物與莓果叢可回到幼苗、已結果瓜藤可回到幼藤、發光漿果藤可回到未結果狀態；草地、菌絲土、灰壤、泥土路、耕地、扎根泥土與粗泥可回到泥土。六種非機關銅材可倒退一個氧化階段，保留蠟層、方向及台階形狀；不處理容器、銅門或銅燈等機關。攻擊樹幹或天然冠葉即可嘗試，成功／拒絕顯示短提示。到期只復原本模組仍持有的年齡或方塊，外部生長、上蠟與換材保留；不補血、不回復背包、不增加戰利品。最新局部原生測試已通過六種真正生成樹，以及小麥、莓果叢、銅材及泥土路；其餘項目不因此視為全數實測通過。詳見 [相容性界線](COMPATIBILITY.md)。

「萬鳥朝拜」改名為「百鳥朝鳳」：兩分鐘鳳凰飛舞與像素振翅，按空白鍵上升、蹲下鍵下降，放開後緩降。飛行只採臨時移動與緩降，不開啟玩家的創造飛行權限；已具有飛行、鞘翅滑翔、漂浮等狀態時讓原有能力優先，重力或摔落傷害受保護時不啟用。

### 本卦與變卦的效果時段

有動爻、因此有變卦時，**前五分鐘採本卦與動爻追加效果，後五分鐘切換為穩定變卦效果**；後半段不再追加動爻效果。沒有動爻時，本卦效果持續十分鐘。切換時段不會再抽卦、不增加圖鑑次數，也不延長正式冷卻。總時段為 12000 個在線遊戲刻，標準 20 TPS 約十分鐘。

### 起卦環境微調

起卦完成時的生命值、生態域、天氣、附近生物、遊戲時間、朝向、天象與雲象，共 **八項因素**，會小幅調整效果強度。天象參考遊戲月相，雲象參考當地雲高與雲色。每項影響不超過 ±3%，合計不超過 ±10%；不改變這次六爻。聊天及結果書顯示本次效果，六十四卦總覽顯示基礎值，條件與權重留待玩家探索。

## 相容性保護與世界設定

一般效果使用本模組自己的暫時修正，到期移除後恢復原有屬性計算；不改武器的基礎參數，也不修改世界生成。正式起卦只清除本模組上一組一般卦象效果，保留其他模組與藥水效果。其他模組仍可能共同影響最終數值，因此整合包應按自身需要列出保護項目。

遊戲實例的 `config/yigua.json` 由服主或單人玩家管理。以下範例明確關閉會改方塊的稀有互動，其他一般功能保持開啟：

```json
{
  "effects_enabled": true,
  "special_events_enabled": true,
  "group_sharing_enabled": true,
  "world_changes_enabled": false,
  "protected_attributes": [],
  "protected_effects": []
}
```

關閉遊戲或伺服器後編輯設定，重新啟動生效：

| 設定 | 用途 |
| --- | --- |
| `effects_enabled` | `false` 時停止套用新卦象效果與稀有事件；保留起卦、圖鑑、閱讀與正式冷卻 |
| `special_events_enabled` | `false` 時停用稀有事件，保留一般卦象效果 |
| `group_sharing_enabled` | `false` 時停用團體共享；個人開關無法繞過 |
| `world_changes_enabled` | 控制分海、障路與五氣攻擊回溯等世界互動；關閉仍保留時間虛影及允許的增益 |
| `protected_attributes` | 列出需保護的原版屬性識別名稱；本模組會跳過調整該屬性的一般效果 |
| `protected_effects` | 列出需停用的一般效果 profile、特殊事件 ID，或神光／五氣／三花增益的完整原版狀態 ID |

首次建立的設定檔可能省略新增欄位。沒有填 `group_sharing_enabled` 時，服主允許共享功能，但每位玩家的送出／接收仍預設關閉。沒有填 `world_changes_enabled` 時，**獨立伺服器為關閉，單人整合伺服器為開啟**；明確填 `true`／`false` 才會覆蓋此差異。

本模組沒有所有領地或 claim 模組都共用的權限掛鉤，不能靠小範圍、到期復原或屬性保護清單推定領地安全。服主應依領地與整合包設定決定是否開啟方塊改動；地形互動關閉不會停用其他一般效果，稀有事件可另外統一關閉。

0.2.1 神光、五氣與三花共用原版狀態的保護檢查，包含狀態 ID、屬性修正與挖掘／呼吸／緩降等原版直接公式；只補上符合設定且當下沒有的狀態，不加入第三方狀態。同名狀態被外部延長、改強度或替換後會保留。正向狀態為 2400 刻、障路為 1200 刻；分海與回溯另按世界時間復原，移動不重置原有效期；障路到期只停止生成。

例如，整合包想保留攻擊傷害的既有計算，再停用特定效果與事件，可設定：

```json
{
  "effects_enabled": true,
  "special_events_enabled": true,
  "group_sharing_enabled": true,
  "world_changes_enabled": false,
  "protected_attributes": ["minecraft:attack_damage"],
  "protected_effects": ["travel", "thunder", "sea", "rapport"]
}
```

屬性請使用當前版本的完整 registry ID，例如 `minecraft:movement_speed`、`minecraft:attack_speed`、`minecraft:gravity` 或 `minecraft:fall_damage_multiplier`；不要填顯示名稱。效果使用基本 profile 名稱，例如 `travel`、`strength`、`airloss`，不填材質倍率衍生名稱。特殊事件 ID 也是設定識別名稱；本手冊不解釋其神秘內容。

資料包可在 `data/yigua/tags/entity_type/rapport_immune.json` 追加需要豁免的生物類型，例如：

```json
{
  "replace": false,
  "values": ["examplemod:custom_guardian"]
}
```

`examplemod:custom_guardian` 是示意名稱，應換成整合包內實際存在的生物 registry ID。標籤為 `yigua:rapport_immune`，預設已有終界龍、凋零怪與伏守者。第三方生物與共同使用的屬性保護由整合包作者明確列出；本模組無法自動讀取所有第三方設定，也未宣稱已驗證任意整合包。

### 想保留占筮、關閉效果

關閉遊戲或伺服器，在既有 `config/yigua.json` 中將 `effects_enabled` 改為 `false`，保留其他欄位與自己的保護清單。重新啟動後即停止套用新的卦象效果與稀有事件；起卦、圖鑑、爻辭閱讀與正式冷卻仍可使用。設定提供開關與保護清單，首版使用上述基礎效果與固定材質倍率。
