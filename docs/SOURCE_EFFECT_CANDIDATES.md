# 古籍短文與一般遊戲效果

目前共有 **32 種一般效果**，全部可由自然基礎卦或既有動爻覆寫取得；中性與需要親自發現的特殊項目另計。下表列出每種效果的一個可追溯代表，並不表示該卦或該爻只有這種傳統解釋。

數值是褐銅錢／木籌的一倍基準。材質在基準上下五成內縮放；環境每項不超過 3%、合計不超過 10%，增益與減益皆會縮放。所有一般效果維持既有本卦前五分鐘、變卦後五分鐘；靜卦十分鐘，僅在線遊戲刻倒數。

## 版本與校核界線

- **伊川來源**：程頤《伊川易傳》，臺灣商務印書館《景印文淵閣四庫全書》第 9 冊所收文淵閣四庫本。模組內 JSON 是自行轉錄的**初錄稿，未經二校**。本輪只逐字核對短句存在、卦位、來源欄位與快照雜湊，未新開影像作逐字二校。影像連結沿用 `image_links`；多頁條目列出全部附列頁面，不推定短句位於第一頁。
- **六爻來源**：康熙五十四年（1715）武英殿刊本《御纂周易折中》，哈佛燕京藏本逐爻影像。沿用既有 `scan-reviewed` 紀錄；本輪沒有另作全書二校。完整 384 爻與用九／用六資料獨立保留，不用伊川稿覆蓋。
- 伊川稿 31–46 卦的 `juan` 欄位保留提供稿的卷二異常；此處不當作確定卷次。恒卦僅卦辭「利貞有攸往」及影像卷次有局部核對；「恒者常久也」等程傳仍未校定，不能宣稱全篇或全書二校。大過與震等卦的疑字紀錄亦保留。
- 全部數值和機制都是**遊戲比喻**。幸運、生命容量、擊退抗性、重力、摔傷、操作距離與氧氣加成不是古籍的遊戲規格或物理論述。火焰時間不是免火，生命上限不是補血，操作距離不是視野，擊退抗性加值也不是相同比例的擊退距離。

## 方位與動爻追加

「順方」取蹇卦特定處難語境：依**實際水平移動**西南加速、東北減速，其他方向與靜止不調整；鏡頭朝向不是判準。它保持目前本卦／變卦的剩餘階段，不刷新十分鐘。這不是把西南、東北或所有世界方位固定為現實吉凶。

無動爻只維持基礎效果；一至二個動爻另加一組，三至五個動爻最多另加兩組，六爻皆變沿用既有特殊卦勢的兩至三組。追加由動爻位置、實際六／九與完整六爻紀錄確定，同 profile 去重，不再次抽籤；沿用本次材質及環境倍率，不延長時長或冷卻。追加每條依據保留實際原爻，位置映射是遊戲規則，**並非 384 爻已完成傳統解釋或逐爻固定屬性分類**。

Library 仍在基礎、動爻覆寫與用辭之間選一條主要規則；動爻追加由遊戲效果層另定。原有九則逐爻覆寫、同優先序取較高動爻，以及用九／用六優先序均保留。

大過上六「過涉滅頂凶无咎」的涉水危險與無咎並存，不等於整卦單純惡；未濟等複合語句也不按單一吉凶機械解讀。
